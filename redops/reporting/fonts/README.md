# Bundled report fonts

Unmodified DejaVu Sans regular and bold, version 2.37, distributed under the
included Bitstream Vera permission notice; DejaVu changes are public domain.
These files were obtained from Ubuntu's fonts-dejavu-core package. Upstream:
https://dejavu-fonts.github.io/ . No Debian packaging code is included.

SHA-256:

```text
b4c632e3cdf9acc7f28758fb5a323c8524d7fc6660d46904d9b6cbe2809c419c  DejaVuSans.ttf
e1d733afbbfce842a1b43dced0c9885a76a4e67290dc7e690c4e9b76ebfc7d23  DejaVuSans-Bold.ttf
```

PDF generation embeds subsets offline. HarfBuzz supplies text shaping and
bidirectional layout through fpdf2. Unsupported glyphs retain explicit Unicode
escapes; this font does not provide universal script coverage.
